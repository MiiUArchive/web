MiiUArchive

A preventive digital preservation initiative for Wii U custom network software, ecosystem components, and documentation.

About the Project

MiiUArchive is an independent archive project dedicated to ensuring long-term access to custom Wii U server infrastructure and open-source tools. By maintaining full Git mirrors and release assets, MiiUArchive prevents data loss caused by repository deletions, domain expirations, or service shutdowns.
