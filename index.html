MiiUArchive

A preventive digital preservation initiative for Wii U custom network software, ecosystem components, and documentation.

About the Project

MiiUArchive is an independent archive project dedicated to ensuring long-term access to custom Wii U server infrastructure and open-source tools. By maintaining full Git mirrors and release assets, MiiUArchive prevents data loss caused by repository deletions, domain expirations, or service shutdowns.

How It Works

The archiving process works automatically using GitHub Actions and public APIs:

  • Daily Mirroring: Scheduled tasks (cron jobs) run git clone --mirror operations to preserve full repository histories, branches, and signed commits intact.
  • Release Harvesting: Automated scripts fetch compiled binaries (e.g., .wms, .wps, .zip) and source code archives directly from release tags.
  • Open Access: All archived data remains accessible in standard Git formats and plain directory trees under GPLv3 licensing for cloning and documentation.
